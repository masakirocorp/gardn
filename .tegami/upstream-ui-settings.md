# Add terminal UI controls

You can now filter keybinding help by shortcut, action, or section, and you can disable pane scrollbars to reclaim the terminal gutter column. You can also choose dot or symbol agent status indicators, set the outer terminal window title, configure the headless terminal size, and route right-clicks to individual panes. Disabling automatic copy now keeps mouse selections visible until you copy or clear them. Context bar, sidebar, and status indicator choices now save without corrupting `config.toml`.

Arbitrary theme token overrides and `ui.accent` compatibility were removed. Appearance now uses built-in themes plus the six terminal accent choices.
