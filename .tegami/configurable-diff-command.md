### Make the Git diff shortcut configurable

The Diff shortcut is now opt-in from Settings > Behavior. Choose a curated review command for Hunk watch mode, plain Git diff, Delta, or Difftastic, or enter any terminal command directly. A configured command shows Diff in the new-tab menu, command palette, and contextual Git actions; leaving it empty keeps those actions hidden.
