# Install Oh My Herdr

This guide installs Oh My Herdr 0.2.18 from source or from the tagged Nix flake.

> **Release availability:** Verified `omh-*` release downloads are not publicly available yet. Use one of the source-based paths below and check the [download status](/download) page before relying on a release artifact.

## Build from a source checkout

Install Rust and Cargo, then run these commands from the repository root:

```bash
git clone https://github.com/masakirocorp/oh-my-herdr.git
cd oh-my-herdr
git checkout v0.2.18
cargo install --path apps/omh
```

`cargo install --path apps/omh` is a checkout command: run it from the cloned repository root, where the workspace and `apps/omh` package are present. It installs the `omh` executable into Cargo's normal binary directory.

## Install with Nix

The repository flake builds the tagged source and exposes the `omh` package:

```bash
nix profile install "github:masakirocorp/oh-my-herdr/v0.2.18#omh"
```

This Nix package is declared for x86_64 and aarch64 Linux and macOS. The Nix path does not provide a Windows installation.

## Check the installation

Verify the executable and version:

```bash
omh --version
```

For the tagged source above, the output starts with `omh 0.2.18`.
