# Product concepts

## Space

A named working area that groups related tabs, panes, and agent changes for one project or task.

## Tab

A workspace subdivision containing one or more panes.

## Pane

A terminal surface attached to a running shell or coding agent.

## Agent

A coding assistant process detected or managed inside a pane.
