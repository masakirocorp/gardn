# Acknowledgments

Gardn thanks these projects and their contributors.

## Herdr
Gardn is a product fork of Herdr, originally created by ogulcancelik.
https://github.com/herdrdev/herdr

## Fly.io Sprites
Gardn adapts authentication handoff code from Fly.io's official Sprites for Herdr plugin.
https://github.com/superfly/herdr-sprites-plugin

## ghui — Kit Langton
Gardn adapts GitHub workflow behavior from ghui by Kit Langton.
https://github.com/kitlangton/ghui

## Fresh IDE
Gardn uses Fresh as its default external editor.
https://github.com/sinelaw/fresh

## terminal-browser
Gardn uses terminal-browser as its default external browser.
https://terminal-browser.sh/

## Hunk
Gardn uses Hunk as its default external diff viewer.
https://github.com/modem-dev/hunk

Fresh, terminal-browser, and Hunk are optional tools installed separately.
